# Лабораторная работа №2 (Вариант 18)

Многопроцессное приложение на языке Си под Windows (Win32 API) с организацией межпроцессного взаимодействия (IPC) через анонимные каналы (pipes)

## Описание
* **Родительский процесс (`parent.exe`)**:
  * Запрашивает имена двух выходных файлов для дочерних процессов;
  * Создает два анонимных канала связи (`pipe1` и `pipe2`);
  * Порождает дочерние процессы (`child1.exe` и `child2.exe`), перенаправляя их `stdin` на чтение из каналов, а `stdout` - в соответствующие файлы;
  * Принимает строки от пользователя: нечетные строки отправляет в `child1`, четные - в `child2`;
  * Ожидает завершения процессов через `WaitForMultipleObjects`
* **Дочерние процессы (`child1.exe`, `child2.exe`)**:
  * Не работают с файлами напрямую - читают из `stdin` и пишут в `stdout`;
  * Удаляют все гласные буквы (латиница и кириллица UTF-8);
  * Диагностические сообщения логируются в `stderr`

## Сборка и запуск

Сборка компилятором GCC (MinGW):
```bash
mingw32-make
```

Запуск:
```bash
./parent.exe
```

Очистка:
```bash
mingw32-make clean
```
